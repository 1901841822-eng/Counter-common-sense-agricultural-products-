# Counter-common-sense-agricultural-products-
A frontend platform for counter-intuitive agricultural products. Features a 4-dimension hometown test, an interactive map for regional discovery, and development model comparisons to promote agricultural branding. Users can create and share personalized product cards. 一个介绍“反常识”农产品的前端网站。支持四维家乡农产品测试、交互式地图查询地区产品及发展模式对照，助力农产品宣传推广。用户可生成个性化农产品卡片并分享给好友。
